# Changelog

All notable changes to `@capper-ui/react` are documented here.

## 0.0.2 — 2026-08-10

### Added

- Named icon exports: `Calendar`, `Clock`, `Github`, `Instagram`, and `X`.
  `Github`, `Instagram`, and `X` are aliases for Phosphor's `GithubLogo`, `InstagramLogo`, and `XLogo`.

## 0.0.1 — 2026-08-06

### Added

- Initial public release: layout atoms, form controls, `Icon`, `CodeBlock`, and the `Card` molecule.
- Starter icon exports: `ArrowLeft`, `ArrowRight`, `Monitor`, `Moon`, `Rss`, and `Sun`.
